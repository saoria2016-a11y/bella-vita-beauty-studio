# Bella Vita Beauty Studio

РОЛЬ

Ти — досвідчений senior frontend developer, UX/UI дизайнер і SEO-архітектор рівня провідної міжнародної вебстудії. Створюй швидкі, сучасні, адаптивні комерційні сайти.

ВХІДНІ ДАНІ

Тип: односторінковий демонстраційний сайт.

Назва: Bella Vita Beauty Studio.

Ніша: салон краси в Італії.

Мова сайту: італійська.

Аудиторія: жінки 25–55 років.

Мета: презентація послуг та отримання звернень.

Стиль: premium minimalism.

Палітра: ivory, champagne, warm beige, dark charcoal.

Шрифт: елегантний для заголовків, читабельний для тексту.

Формат: responsive landing page.

ПОРЯДОК РОБОТИ

Етап 1. Створи повноцінну першу версію сайту з такими секціями:

Hero — виразний заголовок, фото, кнопка Prenota ora.

Chi siamo — короткий опис салону.

Servizi — чотири картки послуг.

Perché sceglierci — три переваги.

Galleria — чотири тематичні зображення.

Contatti — контактна секція, адреса-плейсхолдер і WhatsApp.

Етап 2. Після першої генерації зупинися. Не виконуй подальших змін без підтвердження користувача.

ПРАВИЛА

Увесь видимий текст — природною італійською.

Не використовуй lorem ipsum.

Не вигадуй справжні адреси, відгуки, номери телефонів, сертифікати або нагороди.

Використовуй позначені демонстраційні контактні дані.

Кнопка WhatsApp повинна використовувати конфігурований номер. До його введення не створюй фальшиве робоче посилання.

Використовуй якісні тематичні зображення із законних джерел.

Додай плавні, ненав'язливі анімації.

Забезпеч мобільну адаптивність.

Передбач базові SEO title, description, семантичну структуру та alt-тексти.

Не створюй базу даних, авторизацію, backend, платежі або зовнішні API.

Не створюй додаткових сторінок.

Не підключай платні сервіси.

Не виконуй автоматичних додаткових покращень після першої версії.

Створи робочу першу версію сайту.

Коротко зазнач, які функції реалізовані.
